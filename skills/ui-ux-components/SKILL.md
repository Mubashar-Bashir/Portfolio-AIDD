# UI/UX Components Skill

## Purpose
This skill provides guidance for creating and implementing attractive, accessible, and user-friendly UI components. It emphasizes consistent design patterns, accessibility standards, and optimal user experience across different devices and contexts.

## When to Use This Skill
- Creating reusable UI components for design systems
- Implementing accessibility standards (WCAG 2.1 AA compliance)
- Designing consistent interaction patterns
- Optimizing component performance and responsiveness
- Creating inclusive design solutions
- Establishing design system guidelines

## Core Capabilities

### Component Design
- Create visually appealing and functional UI elements
- Implement consistent design patterns across components
- Design for different states (default, hover, active, disabled)
- Consider mobile-first responsive design

### Accessibility Implementation
- Apply proper ARIA attributes and roles
- Ensure keyboard navigation support
- Implement proper color contrast ratios
- Design for screen reader compatibility

### Interaction Design
- Create smooth and intuitive user interactions
- Implement appropriate feedback for user actions
- Design consistent animation patterns
- Optimize for touch and pointer interactions

### Design System Creation
- Establish consistent design tokens (colors, typography, spacing)
- Create scalable component architecture
- Document component usage guidelines
- Implement theming capabilities

## Key Design Principles

### Visual Hierarchy
- Use typography, color, and spacing effectively
- Guide user attention to important elements
- Maintain visual consistency across the interface

### Interaction Patterns
- Follow platform conventions where appropriate
- Provide clear affordances for interactive elements
- Implement consistent feedback patterns

### Responsive Design
- Design for various screen sizes and orientations
- Implement progressive enhancement
- Optimize touch targets for mobile devices

## Best Practices
- Follow accessibility standards (WCAG 2.1 AA minimum)
- Use consistent design tokens across components
- Implement proper focus management
- Create comprehensive component documentation
- Test components across different devices and browsers
- Design for different user contexts and abilities

## Common Component Patterns

### Buttons
- Primary, secondary, and tertiary variations
- Loading and disabled states
- Icon and text combinations
- Proper focus and hover states

### Forms
- Input validation and error handling
- Label associations and instructions
- Accessible form controls
- Responsive form layouts

### Navigation
- Consistent navigation patterns
- Breadcrumb and pagination components
- Mobile navigation solutions
- Accessibility considerations

### Feedback Components
- Toast notifications
- Loading indicators
- Modal dialogs
- Tooltips and popovers
