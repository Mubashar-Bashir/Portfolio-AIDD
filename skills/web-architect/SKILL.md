# Web Architect Skill

## Purpose
This skill provides guidance for designing scalable, maintainable web application architectures that prioritize performance, security, and extensibility. It focuses on creating robust foundations for web applications that can grow and evolve over time.

## When to Use This Skill
- Planning overall application structure and organization
- Designing scalable system architectures
- Implementing security measures and best practices
- Optimizing application performance and load handling
- Creating maintainable and extensible code organization
- Establishing development patterns and conventions

## Core Capabilities

### System Architecture Design
- Design modular, decoupled system components
- Plan microservices vs monolith approaches
- Create API architecture and service boundaries
- Establish data flow and communication patterns

### Scalability Planning
- Design for horizontal and vertical scaling
- Plan database architecture and optimization
- Implement caching strategies and CDNs
- Consider load balancing and traffic distribution

### Security Architecture
- Implement authentication and authorization patterns
- Design secure API architectures
- Plan data protection and privacy measures
- Establish security monitoring and logging

### Performance Optimization
- Design efficient data fetching and caching strategies
- Plan asset optimization and delivery
- Implement performance monitoring and metrics
- Consider database query optimization patterns

## Key Architectural Principles

### Modularity
- Separate concerns with clear boundaries
- Create reusable and testable components
- Implement proper dependency management
- Design for independent deployment

### Scalability
- Plan for growth from initial design
- Design stateless services where possible
- Consider database scaling strategies
- Implement proper caching layers

### Security
- Apply security at every layer
- Implement proper authentication flows
- Design for data protection and privacy
- Plan for security monitoring and incident response

## Best Practices
- Follow established architectural patterns (MVC, Clean Architecture, etc.)
- Design for testability from the start
- Plan for observability and monitoring
- Document architectural decisions (ADRs)
- Consider deployment and operational concerns
- Design for failure and resilience

## Common Architectural Patterns

### Frontend Architecture
- Component-based architecture
- State management patterns (Redux, Context, etc.)
- Module federation for micro-frontends
- Static site generation vs SSR vs CSR patterns

### Backend Architecture
- API design patterns (REST, GraphQL)
- Microservices vs monolith considerations
- Event-driven architecture patterns
- Database design and optimization

### Integration Patterns
- API gateway patterns
- Service mesh implementation
- Message queue systems
- Event streaming platforms
